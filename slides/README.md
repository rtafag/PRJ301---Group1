## 1. CÁCH MỞ VÀ TRÌNH CHIẾU SLIDE INTERACTIVE

File slide HTML tương tác chuyên nghiệp đã được thiết kế sẵn tại:
👉 `slides/index.html`

### Cách dùng:
1. Nhấp đúp chuột mở file `slides/index.html` bằng bất kỳ trình duyệt nào (Chrome, Edge, Brave, Cốc Cốc).
2. Nhấn phím **F11** trên bàn phím để chuyển sang chế độ **Toàn màn hình (Full Screen)** như một bài thuyết trình chuyên nghiệp.
3. Dùng phím **Mũi tên phải (->)** hoặc **Phím cách (Space)** để sang slide tiếp theo.
4. Dùng phím **Mũi tên trái (<-)** để quay lại slide trước.
5. Thanh tiến trình và bộ đếm `Slide X / 18` ở góc phải giúp quản lý thời gian chính xác.
